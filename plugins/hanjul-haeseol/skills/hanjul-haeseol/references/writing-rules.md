# 해설 작성 규칙

읽는 사람은 **고등학교 수학까지만 알고, 그 과목 용어는 하나도 모르는 사람**이다.
"쉽게 쓴다"는 말은 **정확도를 낮춘다는 뜻이 아니다.** 같은 내용을 아는 말로 바꿔 주는 것이다.

## 1. 용어는 만날 때마다 푼다

앞 쪽에서 설명했더라도 **그 쪽에서 처음 나오면 다시 푼다.** 사람들은 목차를 보고 중간부터 읽는다.

> 축전기(capacitor) = 전하를 담아 두는 그릇. 물탱크라고 보면 된다.
> 용량 C 가 클수록 많이 담기고, 담긴 양이 많을수록 양단 전압이 높아진다.
> 그래서 전압을 보면 얼마나 차 있는지 알 수 있다.

영어 약어는 **풀어 쓴 뒤 뜻까지** 준다.
`KVL = Kirchhoff's Voltage Law(키르히호프 전압 법칙), 한 바퀴 돌면 전압의 합이 0 이라는 법칙`

## 2. 식은 세 단계로 푼다

**① 기호가 뭔지 → ② 식이 하는 말 한 문장 → ③ 왜 이 모양인지**

나쁜 예 — "이 식은 전압의 시간 변화를 나타낸다." (동어 반복이라 아무것도 안 알려 준다)

좋은 예 —
> `dv/dt` 는 **전압이 얼마나 빨리 변하는가**, 즉 변화 속도다. 그래프의 기울기다.
> 앞에 마이너스가 붙었다는 것은 **지금 값이 클수록 빨리 줄어든다**는 뜻이다.
> 물탱크에서 수위가 높을수록 수압이 세서 빨리 빠지는 것과 같다.

## 3. 수학 기호 표준 번역

한 번은 반드시 풀어 준다.

| 기호 | 이렇게 푼다 |
|---|---|
| `d/dt` | 시간에 따라 얼마나 빨리 변하는가. 그래프의 기울기 |
| `∂` (라운드) | 변수가 둘 이상일 때 쓰는 미분. 나머지는 고정하고 하나만 변화시킬 때. 계산은 보통 미분과 같다 |
| `∂²f/∂x²` | 기울기의 기울기, 곧 **휘어진 정도**. 뾰족할수록 크다 |
| `e^(−t/τ)` | τ 시간이 지날 때마다 **약 37 %(=1/e)로 줄어드는 감쇠** |
| `∇·J` | 어떤 지점에서 밖으로 빠져나가는 양 |
| `∫` | 잘게 쪼개 전부 더하기. 넓이 |
| `log` 스케일 축 | 눈금 한 칸이 10 배. 그래서 지수함수가 직선으로 보인다 |
| `≫` | 압도적으로 크다. 작은 쪽은 **버려도 된다**는 신호 |
| `≈` | 큰 것만 남기고 작은 것을 버린 근사 |

**근사가 나오면 무엇을 왜 버렸는지 반드시 밝힌다.** 공학 과목에서 가장 자주 나오는 기술이다.

## 4. 비유는 쓰되 반드시 돌아온다

비유만 남기면 시험에서 못 쓴다. **비유 → 정확한 서술** 순서를 지킨다.

| 개념 | 검증된 비유 |
|---|---|
| 들어오는 양과 나가는 양이 같아 겉보기에 안 변하는 상태 | 수도꼭지와 배수구가 같은 속도로 열린 욕조. 수위는 그대로지만 물은 계속 흐른다 |
| 큰 값에 아주 작은 값을 더한 상황 | 바다에 물 한 컵 붓기. 바닷물은 그대로지만 컵 속 물에게는 큰 변화 |
| 진한 곳에서 옅은 곳으로 저절로 퍼짐 | 향수 뚜껑을 열면 저절로 퍼지는 것 |
| 지수 감쇠 | 많이 남았을 때는 빨리 줄고 적게 남았을 때는 천천히 준다 |
| 테일러 1차 전개 | 언덕에서 한 걸음 옆의 높이를 "지금 높이 + 경사 × 한 걸음"으로 어림하기 |
| 연속방정식 | 은행 계좌. 입금과 출금을 더하면 잔액 변화가 나온다 |
| 서로 붙잡아 함께 움직이는 두 양 | 고무줄로 묶인 두 사람. 떼어 놓으려 하면 당겨서 못 벌어진다 |
| 유효 상수(effective) | 실제로는 둘인데 하나처럼 취급해도 결과가 맞는 값 |

새 비유를 만들 때 기준은 하나다. **비유가 틀린 직관을 심지 않는가.**

## 5. 문체

- `~다` 체 평서문. `~입니다` 를 쓰지 않는다.
- 짧은 문장. 한 문장에 주장 하나.
- 해설 한 덩어리는 2~6 문장. 그보다 길면 줄을 나눈다.
- 강조는 `<b>` 로. 한 덩어리에 두세 곳까지.
- 접속사를 늘어놓지 않는다. `따라서`, `그러므로` 를 연달아 쓰지 않는다.

## 6. 시험 포인트 쓰는 법

**붉은 강조가 실제로 있던 자리만** 쓴다. 그리고 **왜 그 표시가 중요한지**까지 적는다.

> ★ 시험 포인트 — 교수님이 이 식만 따로 크게 동그라미 치셨다.
> **각 항이 무엇을 뜻하는지**와, 조건에 따라 어느 항이 0 이 되는지를 묻는 문제가 나온다.
> 실제로 뒤의 예제 두 개가 전부 "항 지우기" 문제다.

강조가 없는 쪽에는 시험 포인트를 만들지 않는다. 대신 `key` 상자로 정리만 남긴다.

## 7. 자주 하는 실수

- **손글씨를 건너뛴다** — 가장 큰 손실이다. 전부 손글씨인 쪽이 대개 그 과목의 한 장 요약이다.
- **원문을 요약한다** — 원문 칸은 그대로 옮기는 자리다. 줄이면 대조가 안 된다.
- **용어를 한 번만 푼다** — 중간부터 읽는 사람이 막힌다.
- **비유로 끝낸다** — 정확한 서술로 돌아오지 않으면 시험에서 못 쓴다.
- **없는 시험 포인트를 만든다** — 강조 표시의 신뢰도가 떨어진다.
- **사소한 조건을 버린다** — "전원이 없다", "균일하다" 같은 한 줄이 뒤에서 식을 지우는 근거가 된다.
