# 한 줄 해설 (hanjul-haeseol)

강의 슬라이드 PDF 를 **원문 한 줄 : 해설 한 덩어리**로 짝지은 HTML 로 바꾸는 Claude Code 스킬입니다.

교수님이 펜으로 적어 두신 손글씨를 따로 표시하고, 붉은 동그라미가 쳐진 자리는 시험 포인트로 뽑아냅니다.
읽는 사람은 **고등학교 수학까지만 알고 그 과목 용어는 하나도 모르는 사람**이라고 가정합니다.

## 왜 만들었나

시험 기간에 강의 자료를 펴 놓으면 두 가지가 막힙니다.

- 인쇄된 슬라이드는 **결론만 있고 왜 그렇게 되는지가 없습니다.**
- 교수님 손글씨는 **가장 중요한데 나중에 보면 안 읽힙니다.**

PDF 를 통째로 요약시키면 손글씨가 먼저 사라집니다. 텍스트 추출이 필기를 못 읽기 때문입니다.
그래서 이 스킬은 **모든 쪽을 그림으로 떠서 눈으로 보는 것**을 첫 단계로 못 박아 두었습니다.

## 설치

```
/plugin marketplace add brightwindow/hanjul-haeseol
/plugin install hanjul-haeseol
```

Python 3 와 [PyMuPDF](https://pymupdf.readthedocs.io/) 가 필요합니다.

```bash
pip install pymupdf
```

## 쓰는 법

셋 중 아무거나 하면 됩니다.

```
/hanjul-haeseol
```

```
강의자료.pdf 한줄해설로 만들어줘
```

```

```

원본 PDF 옆에 `<원본이름>_한줄해설_고졸판.html` 이 생깁니다. 브라우저로 바로 열립니다.

## 결과물이 어떻게 생겼나

쪽마다 이런 줄이 쌓입니다.

| 칸 | 내용 |
|---|---|
| 회색 상자 | 슬라이드 원문. 영어면 영어 그대로 |
| 붉은 글씨 | 교수님 손글씨 필기 |
| 흰 칸 | 고졸 기준 해설 |
| 노란 상자 | 시험 포인트. **붉은 강조가 실제로 있던 자리만** |
| 파란 상자 | 그래프·그림 설명 |
| 초록 상자 | 정리와 배경 |

해설은 이런 식입니다.

> `dv/dt` 는 **전압이 얼마나 빨리 변하는가**, 즉 변화 속도다. 그래프의 기울기다.
> 앞에 마이너스가 붙었다는 것은 **지금 값이 클수록 빨리 줄어든다**는 뜻이다.
> 물탱크에서 수위가 높을수록 수압이 세서 빨리 빠지는 것과 같다.

> `e^(−t/τ)` 는 **τ 시간이 지날 때마다 약 37 %(= 1/e)로 줄어드는 감쇠**를 뜻한다.

## 지켜지는 원칙

- **원문을 요약하지 않습니다.** 원문 칸은 그대로 옮기는 자리입니다.
- **없는 것을 지어내지 않습니다.** 손글씨가 안 읽히면 `[필기] (판독 불가)` 로 둡니다.
- **시험 포인트를 만들어 내지 않습니다.** 붉은 강조가 실제로 있던 자리만 표시합니다.
- **용어를 만날 때마다 다시 풉니다.** 목차를 보고 중간부터 읽는 사람이 막히지 않게요.

## 안에 무엇이 들었나

```
plugins/hanjul-haeseol/skills/hanjul-haeseol/
├── SKILL.md                   5단계 작업 순서
├── references/
│   ├── writing-rules.md       해설 작성 규칙, 수학 기호 번역표, 검증된 비유 8종
│   └── style.css              결과물 서식
└── scripts/
    ├── pdf_pages.py           PDF → 쪽별 PNG + TXT. 손글씨 쪽을 자동으로 찍어 줍니다
    └── build_html.py          조각 JSON → HTML. 빠진 쪽과 태그 오류를 잡아 줍니다
```

`pdf_pages.py` 는 추출된 텍스트가 유난히 짧거나 조각난 쪽을 **손글씨 쪽으로 표시**합니다.
실제 강의 자료에 돌려 보니 전부 손글씨였던 넉 장을 정확히 집어냈습니다.
